# Zombie Island 2D Platform Game  - Raylib & Go
A simple, unfinished 2D platform game made with Raylib and Golang/Go

Arrow / WASD > Move<br>
Tab > Inventory<br>
Left Mouse Button > Use selected quick slot item<br>
F1 > Debug<br>
F3 > Palette<br>
Esc > Quit<br>
